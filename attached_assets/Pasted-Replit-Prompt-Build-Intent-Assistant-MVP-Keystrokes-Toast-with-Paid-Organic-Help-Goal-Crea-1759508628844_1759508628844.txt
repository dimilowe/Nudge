Replit Prompt: Build “Intent Assistant” MVP (Keystrokes → Toast with Paid + Organic Help)
Goal:
Create a minimal, privacy-friendly prototype of an “Ads as Help” engine:
Capture typed intent (keystrokes) on any webpage (extension, content script).
Match to a small keyword DB (served by a Node/Express API).
Render a toast overlay showing Sponsored (paid) + Free Help (organic).
No heavy AI—just exact & fuzzy string match.
Stack
Chrome Extension (Manifest V3): content script for keystrokes, overlay UI injected with Shadow DOM.
Frontend (Vanilla TS + Vite) for the toast card bundle (built and copied into extension).
Backend: Node + Express with a tiny in-memory DB (JSON). Add simple fuzzy matching.
Typescript everywhere. No DB install required.
Features (MVP)
Keystroke Intent Capture
Listen to input/keyup on text inputs and textareas.
Debounce 500ms; extract last 6 words typed as the “intent phrase”.
POST to /match with { text, url, ts, locale }.
Match Service (Backend)
Seed 6 demo intents:
“timberland boots”
“chicken curry recipe”
“resume template”
“crm for small business”
“cheap flights to miami”
“grow my tiktok”
Each intent has:
type HelpCard = {
  id: string;
  intentPhrases: string[]; // keywords/aliases
  category: "shopping" | "food" | "jobs" | "saas" | "travel" | "creator";
  sponsored?: {
    title: string; subtitle?: string; cta: string; href: string; brand: string;
  };
  organic: {
    title: string; subtitle?: string; cta: string; href: string; source: string;
  };
}
Matching:
Exact includes on normalized text.
Fuzzy: Jaro–Winkler or token overlap ≥ 0.6 on any intentPhrases.
Return best match {sponsored?, organic}; prefer sponsored if present.
Toast Overlay UI
Shadow DOM container bottom-right.
Card shows:
“Sponsored Help” (if exists): title, subtitle, CTA button, tiny “Sponsored” badge.
Divider.
“Free Help”: title, subtitle, CTA.
Close (×) and “Don’t show this again for this site” link (store per-host in chrome.storage.local).
Autodismiss after 12s unless hovered/focused.
Privacy Guardrails (MVP)
Only send last 6 words + page URL origin; never full page text.
Add a simple intent category toggle (context-menu) to enable/disable categories.
Add a red “DEBUG” badge in dev mode; hide in prod.
Local Admin (JSON)
seed/help-cards.json with the 6 examples below.
/reload endpoint to hot-reload JSON without redeploy.

API Requirements
POST /match → { text, url } → returns { sponsored?, organic }.
POST /feedback → { cardId, wasHelpful: boolean } to log feedback (store in memory).
POST /reload → reload JSON seed (dev only).
Add CORS for chrome-extension://*.
Matching Logic (pseudo)
// normalize: lowercase, strip punctuation
// score = max over phrases of (exactInclude ? 1 : jaroWinkler >= .82 ? 0.8 : tokenOverlap >= .6 ? 0.6 : 0)
Return the highest scoring card with:
If sponsored exists → include it as first card.
Always include organic as second card.
Extension Manifest (MV3)
Content script: "matches": ["<all_urls>"], "js": ["content.js"], "run_at": "document_idle".
Permissions: "storage", "activeTab".
Optional contextMenus to toggle categories on/off (store booleans in chrome.storage.local).
Build & Run
One Replit project with two workspaces or one monorepo:
npm run dev:server → starts Express on http://localhost:4000
npm run dev:ext → builds content/overlay bundle into /extension/dist
Load unpacked extension from /extension in Chrome.
Visit any site with a text box and type:
“timberland boots”
“chicken curry recipe”
“resume template”
etc.
Expect a toast within ~0.5–1.0s.
Nice-to-Have (if time permits)
Rate limiting: don’t show more than 1 toast per 15s.
Per-site suppression: “Don’t show on this site again”.
Category toggles (creator, travel, shopping, food, jobs, saas).
Minimal telemetry: count matches & clicks (console + memory).
Acceptance Criteria
✅ Typing a seeded phrase triggers a toast with Sponsored + Free Help.
✅ Closing/suppressing toasts works; suppression persists per site.
✅ Backend returns matches via exact/fuzzy rules.
✅ No page styles are broken (Shadow DOM + isolated CSS).
✅ No full-screen capture or invasive data—only last 6 words are sent.
Deliverables: working Chrome MV3 extension + Node API with seeded matches; clear README with install/test steps.
Design language: minimal, friendly, utility-first. This is an assistant, not an ad pop-up.
