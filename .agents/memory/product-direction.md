---
name: Product direction
description: The user's product positioning, split-testing priorities, and creator-page growth mechanism.
---

Landing-page split testing is a major differentiator for this app versus competitors like Linktree.

**Why:** The user explicitly described it as a major differentiator, so a settings screen alone is not sufficient.

**How to apply:** Prioritize real visitor routing and trustworthy comparisons that help creators see which offers resonate, rather than cosmetic experiment controls.

Public creator landing pages should include a “Powered by Nudg” badge at the bottom.

**Why:** The user wants the badge as a viral mechanic for product-led growth.

**How to apply:** Preserve the discoverable link back to Nudg when changing public-page layouts.

Dashboard page rows should link directly to the selected page's editor preview and, when published, its live URL.

**Why:** The user wants to open the exact landing page they are working on without searching for it in the builder.

**How to apply:** Keep preview and live-page actions easy to find on each page row.
